# [P1] 面向创作的结果页和透明计费

Status: open follow-up; not implemented in this UI change.
Published issue: https://github.com/apexai-sg/multica/issues/3

## 现状

提交成功可进入通用 IssueDetailRoute，包含负责人、优先级、项目等管理属性。
积分价格为翻译文件中的 `$` 字面值，真实结算由配置的 Stripe Price 决定。
积分与每月生成次数是不同门槛，充值是否解除次数限制需明确。

## 验收清单

- [ ] 创作详情优先显示需求、附件、真实状态、待回复内容和成品。
- [ ] 支持预览、下载、复制和继续修改；保留 needs_input 回复闭环。
- [ ] 运行日志和管理属性折叠为高级信息，不编造百分比或阶段。
- [ ] 重试或修改收费前明确报价，完成显示实扣/退款。
- [ ] 商品价格和 ISO 币种从真实支付商品获得，不依赖翻译文案。
- [ ] 说明积分、次数、并发各自限制和充值影响。
- [ ] 验证余额不足、次数耗尽、失败退款及支付未配置。

本次保留原任务回复路径，以免仅移除跳转导致用户无法补充资料。
