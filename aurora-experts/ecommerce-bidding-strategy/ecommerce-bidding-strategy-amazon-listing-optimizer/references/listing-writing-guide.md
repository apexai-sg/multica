# 亚马逊 Listing 写作规范

## 标题公式
Brand + Main Keyword + Key Feature + Usage/Compatibility
- 首字母大写（介词/连词小写）
- 数字用阿拉伯数字（2 instead of two）
- 核心词放最前，前 60-80 字符是搜索结果预览可见区
- 总长度建议 ≤200 字符（不同类目限制不同）

## 五点描述写法
每点结构：
1. 全大写开头短语（FEATURE PHRASE）
2. 冒号后接 2-3 句说明
3. 先痛点、再卖点、后证据
4. 每点埋 1 个次要关键词，不重复

示例：
```
LONG BATTERY LIFE: Enjoy up to 30 hours of playtime with the charging case. Quick charge 10 min = 2 hours use. Ideal for travel and all-day commutes.
```

## Search Terms 规则
- 全小写，空格分隔，不加逗号
- 不重复标题/五点已埋的词
- 不含竞品品牌名、不含 ASIN
- 不含主观词（best/amazing）、不含临时促销词
- ≤250 bytes
- 单复数/大小写 Amazon 自动处理，不要重复

## 违禁词清单
- 医疗类：cure, treat, heal, anti-bacterial（除非有认证）
- 绝对化：#1, best, top, cheapest, guarantee
- 促销类：free shipping, sale, discount（Listing 内不放）
- 敏感词：Amazon, Prime, Kindle（商标类）

## 关键词分层
| 层级 | 位置 | 示例 |
|---|---|---|
| 核心大词 | 标题前半段 | wireless earbuds |
| 长尾词 | 五点/描述 | earbuds with noise cancellation for running |
| 场景词 | 五点/描述 | for gym, for travel |
| 后台词 | Search Terms | 标题未覆盖的同义/长尾 |

## 优化节奏
- 上架后 2 周看数据，没曝光则调整标题核心词
- 有曝光没点击：改主图/价格/标题前 60 字符
- 有点击没转化：优化五点/A+ 内容/评价

## A9 算法权重因素（从高到低）
| 因素 | 权重 | 说明 |
|---|---|---|
| 标题关键词 | 高 | 核心词必须在标题前部 |
| 销量与转化率 | 高 | 历史出单和转化越高，排名越稳 |
| 五点/描述关键词 | 中 | 次要词埋这里 |
| 后台 Search Terms | 中 | 不影响前台展示，补漏 |
| 价格 | 中 | 竞争力影响转化 |
| 评价数与评分 | 中 | 星级 + 评论数影响点击与转化 |
| 库存与发货 | 中 | FBA 或 Prime 标识加权 |
| 点击率 CTR | 中 | 主图/价格影响 |

## 关键词埋词位置优先级
1. 标题前 60-80 字符（最高权重）
2. 标题剩余部分
3. 五点每条开头短语
4. 五点正文
5. 产品描述 / A+
6. 后台 Search Terms（不重复前台词）

## 标题字符预算
- 美国站建议 ≤200 字符（部分类目 ≤150）
- 前 60-80 字符是搜索结果页可见区，必须放核心词+品牌+最卖点
